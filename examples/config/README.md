# Example config repo

Copy this folder to `~/.config/mi6`, or anywhere `MI6_CONFIG` points, and
edit it. The names are made up. The shape mirrors a real one: a personal
domain, a work domain with a clients sub-folder and one client, a hobby
domain, and the `meta` domain that holds `mi6` itself.

`mi6 resolve` in any repo prints which of these layers apply. See
[the design](../../docs/domains.md) for what each file does.
